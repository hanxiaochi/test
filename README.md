# 工程项目信息化管理云平台本地复刻

这是原网站管理平台的本地可运行复刻版本（演示用途，原站点地址已脱敏），项目目录内包含前端页面、静态资源、本地 Node.js 后端、持久化 JSON 数据和工程造价计算逻辑。

## 运行方式

```bash
npm install
npm start
```

默认地址：

```text
http://localhost:3100
```

默认账号：

```text
ys1 / 000000
```

## 验证

在 Windows PowerShell 中建议使用：

```bash
npm.cmd run verify
```

验证内容包括：运行健康检查、已抓原站接口契约、缓存页面动作接口、静态资源、核心造价公式、清单/变更/材料补差/手动计量闭环、材料到场/联系单/资料/工期闭环、流程状态与处理记录闭环和中文数据质量。

## 核心计算

核心造价逻辑位于 `costEngine.js`：

- 合同金额：合同数量 * 合同单价
- 修正金额：修正数量 * 合同单价
- 变更金额：变更后金额 - 变更前金额
- 最终金额：修正金额 + 变更金额
- 已计量金额：累计计量数量 * 清单单价
- 材料补差：补差数量 * (当前价 - 基准价)
- 手动计量：计量数量 * 单价
- 应付金额：已计量金额 + 材料补差 + 手动计量
- 支付比例：应付金额 / 最终金额

## 常用接口

```text
GET  /api/cost/summary
GET  /api/cost/bills
GET  /api/cost/measures
GET  /api/cost/ledger
POST /api/cost/calculate
```

计算示例：

```json
{
  "bills": [{ "quantity": 100, "price": 20 }],
  "variations": [{ "beforeNum": 100, "beforePrice": 20, "afterNum": 120, "afterPrice": 20 }],
  "materialAdjustments": [{ "quantity": 10, "basePrice": 100, "currentPrice": 120 }],
  "manualMeasures": [{ "quantity": 1, "price": 500 }]
}
```

## 说明

原站服务器端源码无法通过浏览器取得，因此本项目按已抓取的原站前端页面、接口调用、表格字段、表单动作和工程造价业务规则重新实现本地后端。OpenConstructionERP 仅作为工程管理、BOQ、成本控制和计量支付业务形态的参考，没有复制其源码。

本地运行数据保存在 `data/runtime-db.json`。如果需要恢复初始演示数据，可以先备份后删除该文件，再重启服务。
